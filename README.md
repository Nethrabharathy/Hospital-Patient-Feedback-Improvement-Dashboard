 # project 🏥 Hospital Patient Feedback & Improvement Dashboard
📌 Project Overview
The Hospital Patient Feedback & Improvement Dashboard is a Business Analysis project designed to transform manual patient feedback collection into a centralized, digital, and data-driven system.
The primary objective of this initiative is to:
•	Improve service quality monitoring
•	Increase departmental accountability
•	Enable data-driven strategic decision-making
•	Enhance overall patient experience
This project demonstrates end-to-end Business Analysis activities including requirement gathering, stakeholder analysis, documentation, process modeling, data analysis, and dashboard reporting.
________________________________________
🎯 Business Problem
NMMS Hospital was collecting patient feedback manually, which resulted in:
•	Lack of centralized data storage
•	Delayed identification of service gaps
•	Limited visibility into department-wise performance
•	No structured mechanism to track improvement actions
This created challenges in proactive decision-making and continuous service improvement.
________________________________________
💡 Proposed Solution
To address these challenges, a centralized digital Patient Feedback & Improvement Dashboard was designed.
The solution enables:
•	Structured digital feedback submission
•	Automated satisfaction score calculation
•	Department-level performance tracking
•	Real-time dashboard visualization
•	Identification of service gaps
•	Tracking corrective and improvement actions
